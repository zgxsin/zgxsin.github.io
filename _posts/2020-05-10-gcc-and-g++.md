<p><strong>GNU compiler collection (GCC)</strong> is a collection of compilers for programming such as C++, C, Objective-C, Java, and Fortran. GCC release is through a free software foundation operated through the command line. The GCC development is by Richard Stallman as part of GNU project.</p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>The GNU provide the optimizing compiler for <strong>C++</strong> which is known as g++. g++ is mainly designed for compiling C++ programming language.</p>
<!-- /wp:paragraph -->

<!-- wp:heading -->
<h2>Main Differences</h2>
<!-- /wp:heading -->

<!-- wp:paragraph -->
<p><strong>GCC is a compiler used for C language compilation whereas g++ is a compiler used for C++ programming language</strong>. There are some differences between these two compilers.</p>
<!-- /wp:paragraph -->

<!-- wp:heading {"level":3} -->
<h3>Filename Extension</h3>
<!-- /wp:heading -->

<!-- wp:paragraph -->
<p>The main difference between GCC and g++ is filename extension. <strong>The gcc treats the .c as a C file where as g++ treats both .c and cpp as C++ files.</strong></p>
<!-- /wp:paragraph -->

<!-- wp:heading {"level":3} -->
<h3>G++ is the complete compiler</h3>
<!-- /wp:heading -->

<!-- wp:paragraph -->
<p>During the compiling phase g++ call the GCC so g++ is the complete compiler and it is not the pre-processor of any other compiler.</p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>g++ compiler builds the object code from source code, and <strong>it does not generate any intermediate C version</strong> of the program.</p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>While compiling C++ program, the GCC does<strong> not link</strong> by default and suppose you require then there are<strong> –Istdc++</strong> command for linking.  The g++ will link to the C++ libraries <strong>automatically</strong> by default.</p>
<!-- /wp:paragraph -->

<!-- wp:heading {"level":3} -->
<h3>Compile Command</h3>
<!-- /wp:heading -->

<!-- wp:paragraph -->
<p>For a compilation of C program,  GCC uses the following command </p>
<!-- /wp:paragraph -->

<!-- wp:syntaxhighlighter/code {"language":"bash"} -->
<pre class="wp-block-syntaxhighlighter-code">gcc program.c  -o binary </pre>
<!-- /wp:syntaxhighlighter/code -->

<!-- wp:paragraph -->
<p>Here program.c is the C source file name where the binary is the executed object file .</p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p></p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>For compilation of  C++ program,  g++ uses the following command </p>
<!-- /wp:paragraph -->

<!-- wp:syntaxhighlighter/code {"language":"bash"} -->
<pre class="wp-block-syntaxhighlighter-code">g++ program.cpp –o binary </pre>
<!-- /wp:syntaxhighlighter/code -->

<!-- wp:paragraph -->
<p>Here program.cpp is the C++ source file name and binary is the executed object file.</p>
<!-- /wp:paragraph -->
