<p>Today I talk about how to locate and search files in Linux system. There are different commands to do that. I will discuss the most used ones .</p>
<!-- /wp:paragraph -->

<!-- wp:heading -->
<h2>Locate Command</h2>
<!-- /wp:heading -->

<!-- wp:paragraph -->
<p>The syntax of <strong><a href="https://man7.org/linux/man-pages/man1/locate.1.html">locate</a></strong> command is:</p>
<!-- /wp:paragraph -->

<!-- wp:syntaxhighlighter/code {"language":"bash"} -->
<pre class="wp-block-syntaxhighlighter-code">locate [OPTION] ...  PATTERN...</pre>
<!-- /wp:syntaxhighlighter/code -->

<!-- wp:paragraph -->
<p>It searches through a prebuilt local database of all files on the file-system generated by the&nbsp;<strong>updatedb</strong>&nbsp;command. Note it is essential to update the database as recent files saved over a period of fewer than 24 hours are not updated into the database by default and the database is updated once within 24 hours span. So the best practice to use locate is to run <code>sudo updatedb &amp;&amp; locate <em>filename</em></code>.</p>
<!-- /wp:paragraph -->

<!-- wp:heading {"level":3} -->
<h3>Usage Example</h3>
<!-- /wp:heading -->

<!-- wp:paragraph -->
<p>In the terminal, run </p>
<!-- /wp:paragraph -->

<!-- wp:syntaxhighlighter/code {"language":"bash"} -->
<pre class="wp-block-syntaxhighlighter-code">echo "test locate" >> tmp_test.txt</pre>
<!-- /wp:syntaxhighlighter/code -->

<!-- wp:paragraph -->
<p>This command does two things: create a file named <code>tmp_test.txt</code> and write "test locate" into this file.  Then run</p>
<!-- /wp:paragraph -->

<!-- wp:syntaxhighlighter/code {"language":"bash"} -->
<pre class="wp-block-syntaxhighlighter-code">sudo updatedb 
locate tmp_test.txt</pre>
<!-- /wp:syntaxhighlighter/code -->

<h2>Which</h2>
<!-- /wp:heading -->

<!-- wp:paragraph -->
<p><strong>which</strong>&nbsp;command in Linux is a command which is used to locate the <strong>executable</strong> file by searching it in the <strong><a href="https://en.wikipedia.org/wiki/PATH_(variable)">$PATH</a></strong> environment variable ((<a href="https://www.geeksforgeeks.org/which-command-in-linux-with-examples/">https://www.geeksforgeeks.org/which-command-in-linux-with-examples/</a>)). If you want to change PATH variable, you can run:</p>
<!-- /wp:paragraph -->

<!-- wp:syntaxhighlighter/code {"language":"bash"} -->
<pre class="wp-block-syntaxhighlighter-code"># Only change PATH temporarily in current shell.
$ export PATH="$PATH:/path/to/dir"</pre>
<!-- /wp:syntaxhighlighter/code -->

<!-- wp:paragraph -->
<p>You can type <code><strong>info which</strong></code> to check the help information for which command.</p>

<h2>Whereis</h2>
<!-- /wp:heading -->

<!-- wp:paragraph -->
<p>whereis is a command which <strong>only finds files</strong> in <strong>certain directories</strong> in the system.</p>
<!-- /wp:paragraph -->

<!-- wp:syntaxhighlighter/code {"language":"bash","highlightLines":"8"} -->
<pre class="wp-block-syntaxhighlighter-code">guzhou@guzhou-laptop:~/tmp$ whereis ifconfig
ifconfig: /sbin/ifconfig /usr/share/man/man8/ifconfig.8.gz
guzhou@guzhou-laptop:~/tmp$ whereis --help

Usage:
 whereis [options] [-BMS &lt;dir>... -f] &lt;name>

Locate the binary, source, and manual-page files for a command.

Options:
 -b         search only for binaries
 -B &lt;dirs>  define binaries lookup path
 -m         search only for manuals and infos
 -M &lt;dirs>  define man and info lookup path
 -s         search only for sources
 -S &lt;dirs>  define sources lookup path
 -f         terminate &lt;dirs> argument list
 -u         search for unusual entries
 -l         output effective lookup paths

 -h, --help     display this help
 -V, --version  display version

For more details see whereis(1).
</pre>
<!-- /wp:syntaxhighlighter/code -->

<h2>Find</h2>
<!-- /wp:heading -->

<!-- wp:paragraph -->
<p>The&nbsp;<strong>find</strong>&nbsp;command in UNIX is a command line utility for <strong>walking a file hierarchy </strong>rooted at each given starting-point<strong>.</strong> If no starting point is specified, '.' is assumed. It can be used to find files and directories and perform subsequent operations on them. It supports searching by file, folder, name, creation date, modification date, owner and permissions. By using the ‘-exec’, other UNIX commands can be executed on files or folders found ((<a href="https://www.geeksforgeeks.org/find-command-in-linux-with-examples/">https://www.geeksforgeeks.org/find-command-in-linux-with-examples/</a>)). The syntax of find command ((<a href="https://man7.org/linux/man-pages/man1/find.1.html">https://man7.org/linux/man-pages/man1/find.1.html</a>)) is:</p>
<!-- /wp:paragraph -->

<!-- wp:syntaxhighlighter/code {"language":"bash"} -->
<pre class="wp-block-syntaxhighlighter-code">find [-H] [-L] [-P] [-D debugopts] [-Olevel] [starting-point...] [expression]</pre>
<!-- /wp:syntaxhighlighter/code -->

<!-- wp:paragraph -->
<p>The [expression]  is a kind of query specification describing how we match files and what we do with the files that were matched.  An expression is composed of a sequence of things. You need to specify finding patterns and what to find. I will take about them with the examples.</p>
<!-- /wp:paragraph -->

<h2><strong>&nbsp;Search Text within Multiple Files</strong></h2>
<!-- /wp:heading -->

<!-- wp:syntaxhighlighter/code -->
<pre class="wp-block-syntaxhighlighter-code">find . -type f -name "*.txt" -exec grep "test" {} \;</pre>
<!-- /wp:syntaxhighlighter/code -->

<!-- wp:image {"id":776,"sizeSlug":"large"} -->
<!-- Image lost in the WordPress migration: uploads/2020/03/image-22.png -->
<!-- /wp:image -->

<!-- wp:paragraph -->
<p>This will give us the text containing "test" in all <strong>files</strong> in <strong>current directory</strong> (recursive) with a ".txt" suffix. Here we use <code>-exec</code>:</p>
<!-- /wp:paragraph -->

<p><strong>-exec</strong></p>
<p style="padding-left: 40px;">Execute command; true if 0 status is returned. All following<br>arguments to find are taken to be arguments to the command<br>until an argument consisting of ';' is encountered. <strong>The</strong><br><strong>string '{}' is replaced by the current file name being</strong><br><strong>processed everywhere it occurs in the arguments to the</strong><br><strong>command, not just in arguments where it is alone, as in some</strong><br><strong>versions of find</strong>. <strong>Both of these constructions might need to</strong><br><strong>be escaped (with a `\') or quoted to protect them from</strong><br><strong>expansion by the shell</strong>. &nbsp;The specified command is run<br>once for each matched file. The command is executed <strong>in the</strong><br><strong>starting directory.</strong> There are unavoidable security problems<br>surrounding use of the -exec action; you should use the<br><strong>-execdir </strong>option instead.</p>
